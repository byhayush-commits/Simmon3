# Aurix

**A music player for Android. Search, queue, and play — with the screen off.**

No account. No ads. No tracking.

---

## Features

1. **Search** — songs, artists, albums & playlists with artwork
2. **Background playback** — keeps playing with screen off
3. **Lock-screen controls** — play/pause, skip, seek ±10s
4. **Queue** — add, remove, reorder, shuffle, repeat
5. **Library** — liked songs, playlists, imported playlists
6. **History** — track what you played and when
7. **Resume** — queue & playback position survive restart
